# ASE-Portfolio-Magpusao

# Course Introduction
This course introduces Agentic Software Engineering: building software in which AI agents plan and act with some autonomy. It covers:

- **Agentic systems:** how AI agents differ from traditional applications
- **Agile and Scrum:** developing software in short, iterative cycles
- **Git and GitHub:** version control and collaboration
- **Responsible AI:** safety, security, privacy, and ethics, guided by the NIST AI Risk Management Framework

# Personal Learning Goals
- Use Git branching, commits, and pull requests confidently in team projects.
- Understand how to design and test AI agents whose behavior is not fully predictable.
- Apply the NIST AI Risk Management Framework to identify and reduce risks in a project.
- Practice Agile and Scrum by planning work in sprints and reflecting on results.
- Build a small agentic application with proper safeguards and human oversight.

# Reflection from Part A

Writing the concept analysis showed me that agentic software is different from traditional software mainly because its behavior is not fully predictable. That makes testing harder and makes Agile practices, such as small increments and regular reviews, especially useful.

The biggest takeaway for me is that risks like harmful actions, bias, privacy leaks, and prompt injection must be planned for from the start. Human oversight is what keeps accountability with people. I want to apply these ideas in the projects I build in this course.
